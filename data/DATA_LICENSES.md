`data/student/` and `data/teacher/` mix rows from public datasets, which keep their original licenses, with synthetic
rows that we release. Licenses were read from the Hugging Face dataset cards on 2026-09-28.

## Code sub-sources

Eurus-2-RL-Data takes its code problems from four datasets. The `metadata.data_source` field of every code row names
its sub-source.

| `data_source` | Dataset named by Eurus-2-RL-Data | License on its dataset card |
|---|---|---|
| `codecontests` | [deepmind/code_contests](https://huggingface.co/datasets/deepmind/code_contests) | CC BY 4.0 |
| `taco` | [BAAI/TACO](https://huggingface.co/datasets/BAAI/TACO) | Apache-2.0 |
| `apps` | [codeparrot/apps](https://huggingface.co/datasets/codeparrot/apps) | MIT |
| `codeforces` | [MatrixStudio/Codeforces-Python-Submissions](https://huggingface.co/datasets/MatrixStudio/Codeforces-Python-Submissions) | unverified: the card states no license |

The problem statements in these datasets come from competitive-programming sites, including Codeforces, AtCoder,
CodeChef, Kattis and others. Their copyright stays with the original authors. We redistribute them only as part of
the upstream datasets, under the terms those datasets state.

## Intermediate copy

The paper's pools were read from [Keven16/G-OPD-Training-Data](https://huggingface.co/datasets/Keven16/G-OPD-Training-Data)
(rev. `c9bc678`). Its card states Apache-2.0.

Its math and code files add nothing beyond the operations described in `data/README.md`:
- filtering and deduplicating DeepMath-103K;
- dropping the Eurus system message;
- appending a one-line instruction to each prompt.

`build_data.py --source upstream` therefore rebuilds every row from the two MIT-licensed originals alone.
